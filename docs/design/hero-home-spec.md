# 首页 Hero 设计实现规格(交接文档)

> 来源:Penpot 文件页面「博客首页 · 仿Sakura」/ 画板「首页 Hero · 1440×810」。
> 视觉基准:`docs/design/assets/hero-full.png`(整板导出)。
> 配套资产:`docs/design/assets/icon-{search,language,sun}.svg`。
> 相关文档:`docs/design/penpot-design-tokens.md`(Penpot token 库结构)。
> 日期:2026-09-14。所有颜色统一深色 `#1A1A1D`,背景为浅色全屏图。

## 1. 画布与整体结构

- 设计尺寸:1440 × 810(桌面端一屏 hero,`100vh` 语义)
- 层次(自底向上):全屏背景图 → 左侧菜单 → 顶栏(logo + 右上图标组)→ 底部滚动指示
- 页面即首页,无独立导航条跳转自身

## 2. 背景图

- 全屏 cover,当前 Penpot 里是一张占位雪景图(wallhaven 来源,**版权未确认,上线前建议替换为自有/已授权图片**)
- 图片整体偏浅色,因此所有前景元素用深色 `#1A1A1D`

## 3. 顶栏

高 64px 的透明层,不滚动时覆盖在背景上。

### 3.1 Logo(左上)

| 属性 | 值 |
|---|---|
| 文本 | `Naloxonee` |
| 字体 | Google Sans Flex,weight 400(Google Fonts 可直接引) |
| 字号 | 24px |
| 颜色 | `#1A1A1D` |
| 位置 | x=40,在 64px 顶栏内垂直居中 |
| 行为 | 链接到首页 `/` |

### 3.2 右上图标组(从左到右:搜索 → 语言 → 主题切换)

| 图标 | 资产 | 圆心坐标 | 说明 |
|---|---|---|---|
| 搜索 | `icon-search.svg` | (1303, **30**) | 光学中心比另外两个高 2px(手柄下垂的视觉补偿) |
| 语言选择 | `icon-language.svg` | (1347, 32) | 地球仪 |
| 明亮/暗黑切换 | `icon-sun.svg` | (1391, 32) | 当前显示太阳(亮色态);暗色态切换为月亮 |

- 图标主题色:`#1A1A1D`(暗黑模式下换 `#E8E8EA`)
- 圆心距统一 **44px**,最右图标右缘距画板右边缘 **40px**
- 视觉尺寸:搜索镜圈 15px、地球仪 19px、太阳光芒跨 20px;垂直均以 y=32 为轴(搜索除外,见上)
- 线宽:环 1.6–1.8,光芒/手柄 2.2,全部圆头端点

## 4. 左侧菜单(galgame 式纯文字导航)

容器:x=240,首项文字顶 y=228,行距(顶到顶)**76px**,5 项。

| # | 中文 | 英文角标 | 跳转(建议路由) |
|---|---|---|---|
| 1 | 文章 | ARTICLES | `/articles` |
| 2 | 工程 | PROJECTS | `/projects` |
| 3 | 喜欢 | FAVORITES | `/favorites`(番剧+音乐合并页) |
| 4 | 朋友 | FRIENDS | `/friends` |
| 5 | 关于 | ABOUT | `/about` |

### 4.1 中文主标

- 字体:**Noto Sans SC**,weight 500,28px
- 颜色:`#1A1A1D`,不透明度 90%

### 4.2 英文角标

- 位置:中文**右侧 6px**,与中文**底部对齐**(像后缀缀在右下)
- 字体:Rubik 400,11px,letter-spacing 2px
- 颜色:`#1A1A1D` @ 35%

### 4.3 交互细线

- 位置:文字块下方约 15px(主标顶 + 44px),宽 **56px**,左对齐
- 默认态:1px,`#1A1A1D` @ 10%
- **hover/当前态:2px,`#1A1A1D` @ 90%**(设计稿中以第 1 项示范)

### 4.4 布局参考值(y 坐标,基于画板顶部)

| 项 | 主标顶 | 细线顶 |
|---|---|---|
| 文章 | 228 | 272 |
| 工程 | 304 | 348 |
| 喜欢 | 380 | 424 |
| 朋友 | 456 | 500 |
| 关于 | 532 | 576 |

实现时可用 flex column + gap 语义化(76px 步距 = 34px 行高 + 42px 间隔),不必硬编码绝对位置。

## 5. 底部滚动指示

- 双层人字箭头(`⌄` 字形或 SVG chevron),字号 42px
- 上层:`#1A1A1D` 100%;下层:40%,垂直错位 28px
- 水平居中(x=720),顶部箭头 y≈678
- 行为:点击平滑滚动到 hero 下方内容;建议加缓慢上下浮动动画

## 6. 交互行为清单(实现时需要)

1. 菜单 5 项 → 对应路由跳转;hover 触发细线加粗加深(见 4.3)
2. 搜索图标 → 打开搜索浮层(设计稿未展开,自行发挥,风格参照 mac 风单色)
3. 语言图标 → 中/英(或其他)切换;当前设计仅中文态
4. 太阳图标 → 明暗主题切换;暗色态图标换月亮,前景色换 `#E8E8EA`(对应 token 库 dark 主题,见 penpot-design-tokens.md)
5. 滚动指示 → 平滑下滚

## 7. 字体加载

| 字体 | 用途 | 来源 |
|---|---|---|
| Google Sans Flex | logo | Google Fonts |
| Noto Sans SC (500) | 菜单中文 | Google Fonts |
| Rubik (400) | 英文角标 | Google Fonts |

注意:Noto Sans SC 与 Rubik 建议按需子集化(中文全量 woff2 较大)。

## 8. 响应式建议(设计稿未覆盖,自行决定)

- <1024px:左侧菜单可移至底部横排或收进抽屉;菜单与背景人物可能重叠,注意可读性
- 背景 `object-fit: cover` 保证任意比例下不变形
