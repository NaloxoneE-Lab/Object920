# 首页 Hero 设计实现规格(交接文档)

> 来源:Penpot 文件页面「博客首页 · 仿Sakura」/ 画板「首页 Hero · 1440×810」。
> 视觉基准:`docs/design/assets/hero-full.png`(整板导出)。
> 配套资产:`docs/design/assets/icon-{search,language,sun}.svg`。
> 相关文档:`docs/design/penpot-design-tokens.md`(Penpot token 库结构)。
> 日期:2026-09-14。所有颜色统一深色 `#1A1A1D`,背景为浅色全屏图。

## 1. 画布与整体结构

- 设计尺寸:1440 × 810(桌面端一屏 hero,`100vh` 语义)
- 层次(自底向上):全屏背景图 → 左侧菜单 → 顶栏(logo + 右上图标组)→ 底部滚动指示
- 页面即首页,无独立导航条跳转自身

## 2. 背景图

- 全屏 cover,当前 Penpot 里是一张占位雪景图(wallhaven 来源,**版权未确认,上线前建议替换为自有/已授权图片**)
- 图片整体偏浅色,因此所有前景元素用深色 `#1A1A1D`

## 3. 顶栏

高 64px 的透明层,不滚动时覆盖在背景上。

### 3.1 Logo(左上)

| 属性 | 值 |
|---|---|
| 文本 | `Naloxonee` |
| 字体 | Google Sans Flex,weight 400(Google Fonts 可直接引) |
| 字号 | 24px |
| 颜色 | `#1A1A1D` |
| 位置 | x=40,在 64px 顶栏内垂直居中 |
| 行为 | 链接到首页 `/` |

> 实现偏差(2026-10-24,用户逐次试值 21 → 24 → 26 → **29**):左右墨迹留白统一由
> `.header-inner` 的 `--header-gutter` 控制,当前取 **29px**(左内边距 29 − 2.1 字形左边距,
> 右内边距 29 − 8 图标内缩),顶部留白 23px,左右严格对称。设计稿的 x=40 是盒子左边距,
> 视觉上左侧留白明显大于顶部留白,故改为墨迹对齐;换算依据见 `Header.astro` 的注释。

### 3.2 右上图标组(从左到右:搜索 → 语言 → 主题切换)

| 图标 | 资产 | 圆心坐标 | 说明 |
|---|---|---|---|
| 搜索 | `icon-search.svg` | (1303, **30**) | 光学中心比另外两个高 2px(手柄下垂的视觉补偿) |
| 语言选择 | `icon-language.svg` | (1347, 32) | 地球仪 |

- 图标主题色:`#1A1A1D`(暗黑模式下换 `#E8E8EA`)
- 圆心距统一 **44px**,最右图标右缘距画板右边缘 **40px**
- 视觉尺寸:搜索镜圈 15px、地球仪 19px、太阳光芒跨 20px;垂直均以 y=32 为轴(搜索除外,见上)
- 线宽:环 1.6–1.8,光芒/手柄 2.2,全部圆头端点

> 实现偏差(2026-10-24,与 3.1 同批):为与左侧 logo 的墨迹留白对称,最右图标**墨迹**
> 距右缘收到 **29px**(图标在 34px 按钮盒里居中,母盒右内边距 21px)。设计稿的 40px
> 是圆心坐标推算的盒子值,不是墨迹值。
>
> 另一处同批偏差:上表「搜索高 2px」的补偿**已删除**(`Header.astro` 里原
> `translate: 0 -2px`)。设计稿那版搜索图标的手柄伸到圆外,才需要抬高;本仓这枚放大镜
> 的墨迹框在 viewBox 里本来就居中,抬高后它的墨迹中心落在 y=29.5,而其余三枚是 31.5,
> 肉眼可见「搜索比别的都高」。去掉后四枚墨迹中心统一为 **31.5**。
>
> 2026-10-25 又补了两处(用户反馈「搜索看起来更小/更高一点」):①放大镜按 20px 渲染时墨迹
> 只占 viewBox 的 20/24(16px),而地球仪/调色板占 22/24(18px),确实小一圈 → 改成 **22px 渲染**
> 并把 stroke 折回 1.82,墨迹 18×18 而线宽仍是 1.67px;②`.search-box` 这层没吃到
> Header 的 `display:flex`(被 SearchBox 自己的 scoped 样式压掉),里面 34px 的 inline-flex
> 按钮坐在行盒顶部,整枚图标因此比其余**高 0.8px** → 给 `.search-box` 补了 `display:flex`+居中。
> 现四枚图标墨迹框统一 18×18、中心 y=31.5(音乐图标本身 17×16,中心同为 31.5)。

## 5. 底部滚动指示

- 双层人字箭头(`⌄` 字形或 SVG chevron),字号 42px
- 上层:`#1A1A1D` 100%;下层:40%,垂直错位 28px
- 水平居中(x=720),顶部箭头 y≈678
- 行为:点击平滑滚动到 hero 下方内容;建议加缓慢上下浮动动画

## 6. 交互行为清单(实现时需要)

1. 菜单 5 项 → 对应路由跳转;hover 触发细线加粗加深(见 4.3)
2. 搜索图标 → 打开搜索浮层(设计稿未展开,自行发挥,风格参照 mac 风单色)
3. 语言图标 → 中/英(或其他)切换;当前设计仅中文态
4. 太阳图标 → 明暗主题切换;暗色态图标换月亮,前景色换 `#E8E8EA`(对应 token 库 dark 主题,见 penpot-design-tokens.md)
5. 滚动指示 → 平滑下滚

## 9. 顶栏交互:悬停即弹(2026-10-25)

图标组顺序改为 **搜索 → 音乐 → 主题 → 语言**。四个按钮共用一套「鼠标碰一下就出面板」的机制,
实现在 `src/lib/hover-panels.ts`,组件不感知时序:

- 包装元素标 `data-hover-panel`,组件监听 `hoverpanel:open` / `hoverpanel:close`(CustomEvent),
  用自己的开合函数响应 —— 开合逻辑仍归各组件所有。
- 仅 `(hover: hover) and (pointer: fine)` 生效;进入即开(0ms),离开 300ms 宽限,
  指针滑进面板就取消关闭;同时只开一个(开 A 时给其它发 `close`,带 `detail.force`,
  连「点击后才保持」的搜索 active 态也要让位)。
- 别用 pointermove 时间戳去甄别「假 pointerenter」:合成指针可能只发 enter 不发 move。
  现在用「指针是否仍在元素内」的标记。

### 9.1 搜索面板(先搭结构,视觉待重做)

三态:`idle` → `peek`(悬停:屏幕中央的浅色悬浮面板,**不虚化背景**、顶栏仍可见、不抢焦点)
→ `active`(点击/聚焦:全屏 `backdrop-filter` 虚化 + 实底面板)。

peek 里输入框还没有真实输入行为,框内文字当提示用:居中显示
`common.search.peek-hint`(中文「再次点击进入搜索面板」),由 JS 在切态时换 placeholder,
居中由 `.search-box[data-mode='peek'] .search-input { text-align: center }` 负责。

- 状态挂在 `.search-box[data-mode]`,样式在 `SearchBox.astro`;
- 全屏遮罩 `.search-backdrop` 必须 `pointer-events: none`:否则 active 期间指针停在遮罩上,
  收遮罩时浏览器补发 `pointerenter`,面板会「刚关又弹回来」;
- 主动收起(Esc / 点按钮 / 点页面)后置 `hoverNeedsLeave`,要求指针先离开再进入,
  否则同样会被那记补发的 enter 立刻弹回。
